## Running

Java sources are compiled with `javac` and run with `java`:

```bash
cd 0_Labuladong/basics/1_output_input
javac Main1.java
java Main1
```

## Git notes

- Compiled output (`bin/`, `*.class`) and local scratch files (`CMDS`, `link`, `link.txt`) are gitignored — commit only `.java` sources.
- `work.code-workspace` (VS Code multi-root workspace: this repo + the Obsidian notes vault) is versioned here.
- Notes vault lives in a separate repo (`obsidian_master/DSA`).
